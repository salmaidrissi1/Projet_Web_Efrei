Objectif du site

Le but est de présenter le département informatique de manière claire : formations, équipe pédagogique, vie étudiante, partenariats et contact.

Le site respecte une organisation simple avec des fichiers séparés : HTML pour la structure, CSS pour le style et JavaScript pour les interactions.
